Sum up 23 November's world news in one image — a front page of 31 stories.

**Heroes:** AI rout hits Asia (Kospi −3.3%), Guterres urges AI rules at the Bridgetown summit, US lead over China at a record low (Asia Power Index gap 5.3).

**How to run:** `python3 main.py` writes `entry.png` (1024×1024) to `$MAKEFUN_OUTPUT_DIR` (default `out/`). Stdlib only — no PIL needed at run time.

**Layout:** masthead → number strip → region bar → 3 hero scenes → 10 cards → world map + ALSO list → DATE CHECK (stories dated other days are listed there, never as stories).

**Sources:** Reuters, AP, Bloomberg, AFP, Yonhap, BBC, WSJ, NYT, ESPN, Lowy Institute. REPORTED = confirmed by wires; CLAIM = one side's claim, not independently confirmed.
